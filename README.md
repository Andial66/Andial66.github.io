# Santiago Cifuentes — personal website

This is the complete static website, including the enlarged pencil portrait and updated CV.

## Publish on GitHub Pages

1. Extract the ZIP on your computer.
2. Open your GitHub Pages repository and choose Add file → Upload files.
3. Upload the contents of this folder, including assets. index.html must be at the repository root.
4. Commit the files to main.
5. Open Settings → Pages. Choose Deploy from a branch, main, and /(root), then Save.
6. Wait for deployment; Settings → Pages will show the website address.

Relative asset links support both username.github.io and username.github.io/repository/.
No Node.js, dependencies, or compilation are needed.

## Update later

Edit index.html to change the bio, positions, visits, or publications.
Edit assets/*.css to change styling.
Replace santiago-cifuentes-cv.pdf with a new PDF using the same filename to update the CV.

GitHub guide: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site
